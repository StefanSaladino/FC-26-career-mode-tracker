# Editorial Release Checklist

Complete as applicable for each match/event. The review is proportionate: major matches receive full treatment, routine matches may be lighter, and unexpected events can elevate coverage.

- [ ] Read AGENTS.md, EDITORIAL_CONSTITUTION.md and sole CANON.md.
- [ ] Confirm match/result/goal minute/assist and competition with manager-supplied facts. Mark unknowns as unknown.
- [ ] Decide major, routine or exceptional; choose number of stories for actual news value, not quotas.
- [ ] Check article angle, depth, varied journalist bylines, coherent chronology, meaningful comments and authentic replies.
- [ ] Check established player personalities and monthly interview/feature coverage; log justified exception.
- [ ] For manager press: ask HERE, respect accept/refuse/postpone/end; never invent his answers. Sandro may independently decline or answer his own press.
- [ ] Review identity references contextually. Internal media director is not a public character; footballers sharing his surname are valid.
- [ ] Check cover image existence and, if possible, visually verify mobile/desktop cropping; distinguish file checks from rendered QA.
- [ ] Update current hero, news, result, fixtures, record, verified standings, stats, ticker, whispers and pressure points as relevant.
- [ ] Update only CANON.md and EDITORIAL_COVERAGE_LEDGER.json.
- [ ] Run `node scripts/validate-editorial.mjs`; fix technical errors; review nonblocking editorial warnings with a documented decision.
- [ ] Confirm script load order and commits; verify live rendering if tools allow. Never report unperformed QA as done.

**Warnings**: APPROVE (record context), REVISE (edit), or DEFER (request clarification). No mechanical censorship.
